Can projects be handled remotely?

Many permit-level electrical engineering projects can be handled remotely using drawings, photos, equipment schedules, utility information, and AHJ comments.

No. Each project is reviewed for the applicable jurisdiction, code basis, utility requirements, and AHJ permit expectations.
